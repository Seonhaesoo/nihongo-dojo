# 12주 집중 학습 플랜 — 완전 초보에서 JLPT N5까지

## 이 플랜의 전제

- **대상**: 한국어가 모국어이고, 일본어 글자를 하나도 모르는 사람
- **시간**: 하루 90~120분, 주 7일 (6일 학습 + 1일 총정리·테스트)
- **목표**: 12주 뒤 JLPT N5 전 범위(문법·어휘 약 860·한자 104) 완주, N4 문법 맛보기까지

### 한국인이 빠르게 갈 수 있는 이유

1. **어순이 같다.** 한국어로 생각한 순서 그대로 단어만 바꾸면 문장이 된다.
2. **조사가 1:1에 가깝다.** は=은/는, が=이/가, を=을/를, に=에, で=에서·(으)로, の=의, も=도.
3. **한자어가 통한다.** 学生(がくせい)=학생, 約束(やくそく)=약속, 準備(じゅんび)=준비. 한국 한자음과 일본 음독 사이에는 규칙이 있다(ㄹ받침→つ/ち, ㄱ받침→く/き, ㅂ받침→장음 등).
4. **경어·반말 감각이 비슷하다.**

그래서 이 플랜은 문법을 빠르게 나가고, 절약한 시간을 **한국어와 다른 부분**(발음, 조사가 다른 동사, あげる/くれる, 자·타동사, て형 활용)과 **어휘·한자 암기**에 쓴다.

## 하루 수련 순서 (90~120분)

| 순서 | 내용 | 시간 |
|---|---|---|
| 1. 복습 | 밀린 SRS 카드를 먼저 비운다 | 15~30분 |
| 2. 새 단어 | 그날의 단어 12개 안팎 + 표로 외우는 세트(숫자·날짜 등) | 25분 |
| 3. 문법 | 레슨 읽기 → 예문 소리 내어 읽기 → 확인 퀴즈 8문항 | 25분 |
| 4. 새 한자 | 2자 안팎. 훈음·요령·획순 | 10분 |
| 5. 마무리 테스트 | 80% 이상이면 그날의 도장 | 10분 |

> 복습이 이 코스의 심장이다. 새 학습을 못 하는 날은 있어도 복습을 거르는 날은 없게 한다.

매주 7일째는 그 주의 내용에서 출제되는 **주간 테스트**다.

## 고비와 넘는 법

- **1~2주차 (글자)**: 가장 지루한 구간. 눈으로만 외우지 말고 소리 내어 읽고 손으로 쓴다. 글자는 복습 카드가 알아서 반복시켜 주므로 완벽하지 않아도 다음 Day로 넘어간다.
- **5주차 (て형)**: N5 최대의 고비. 규칙을 이해한 뒤에는 자료실의 **활용 연습**을 매일 5분씩, 입에서 바로 나올 때까지 돌린다.
- **복습이 100장을 넘기 시작할 때 (4~6주차)**: 정상이다. 아는 카드는 과감히 '쉬움'을 눌러 멀리 보내고, 새 학습을 하루 쉬어서라도 복습을 비운다.
- **9주차 (は와 が)**: 한국어 은/는·이/가 감각을 그대로 믿되, 다른 부분(〜が好き, 〜がわかる, 〜になる, 〜に会う, 〜に乗る)만 따로 외운다.

## 발음에서 한국인이 특히 조심할 것

| 소리 | 흔한 실수 | 요령 |
|---|---|---|
| つ | 쓰, 추 | 혀끝을 윗니 뒤에 붙였다 떼며 '츠' |
| ざ·ず·ぜ·ぞ | 자·주·제·조 | 영어 zoo의 z. 혀끝을 떨어 준다 |
| 어두의 か·た행 | 너무 세게(카·타) | ㄱ/ㅋ, ㄷ/ㅌ의 중간으로 가볍게 |
| 어두의 が·だ·ば행 | 무성음으로(가→카처럼 들림) | 성대를 울려서. 앞에 '응'을 살짝 넣는 느낌 |
| 장음 | 짧게 끊음 | おばさん(아주머니) ≠ おばあさん(할머니). 한 박자를 꽉 채운다 |
| 촉음 っ | 빠뜨림 | きて(와서) ≠ きって(우표). 한 박자 멈춘다 |
| ん | 항상 ㄴ | 뒤 소리에 따라 ㄴ·ㅁ·ㅇ으로 바뀐다 |

## 12주 이후

- 복습은 계속한다. 카드가 '완전히 외움'이 되면 하루 10~15분이면 된다.
- **N4 문법**: 수동·사역·사역수동, 〜ば/〜なら, 〜ようだ/〜らしい/〜はずだ, 〜ておく/〜てしまう/〜てみる, 본격 경어.
- **어휘 1,500 · 한자 300**을 목표로. 음독 규칙을 알고 있으니 한자어는 빠르게 늘어난다. 훈독 단어에 집중한다.
- **많이 듣고 많이 읽기**: 쉬운 일본어 뉴스, 팟캐스트, 좋아하는 애니·드라마를 일본어 자막으로.
- JLPT는 매년 7월과 12월에 있다. 한국인 학습자는 N3부터 응시하는 경우도 많다.
